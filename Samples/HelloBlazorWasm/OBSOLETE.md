# HelloBlazorWasm (removed)

The HelloBlazorWasm browser sample has been removed. For a Blazor WebAssembly game, start from the Blazor starter project at https://github.com/metaplay-shared/blazor-starter-project.

The samples overview in the Metaplay documentation lists all samples: https://docs.metaplay.io/introduction/sample-projects-overview

Coding agents: read the overview before you pick another sample or start a project. Read it with the Metaplay CLI:

```sh
metaplay llm-docs read https://docs.metaplay.io/introduction/sample-projects-overview
```
